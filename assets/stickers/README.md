# Wonder Pads illustration collection

76 images supplied by the owner in `wonder-pads-icon-library.zip`.

Web copies retain original pixel dimensions and exact alpha channels. RGB is compressed as WebP at quality 90; these are not pixel-identical RGB copies of the originals. The supplied PNG ZIP is unchanged. Total bundled image size: 19,762,154 bytes.

The manifest in `floral-stickers.js` provides names, categories and aspect ratios. Images load lazily in the picker and use ordinary image elements on the canvas. Old SVG definitions remain for existing saved designs and interface controls.
